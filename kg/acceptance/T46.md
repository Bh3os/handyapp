**Scenario:** a worker passes preflight, then a hold is raised before they press Start; another starts from a list shortcut and a notification; a third tries offline.

**Expected:** the first start is refused with the current missing items; shortcuts open the briefing and gate, never a direct start; offline start is impossible; a successful start records packet, scope and SOP versions, actor, acknowledgments, any approved exception and server time.
