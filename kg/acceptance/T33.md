**Scenario:** a verified customer selects options, reads the terms, ticks the unchecked-by-default box, types their full name and presses "Approve Estimate"; other attempts send an altered total, use stale verification, or decline with a reason.

**Expected:** the approval stores version, terms version ID and hash, payment-term text, options, total, name, verified contact and server time; altered totals are refused; stale verification asks for a new code and keeps the options; decline keeps history and notifies staff; the approval receipt with PDF sends once; staging approvals are marked TEST.
