**Scenario:** an assigned worker reveals a code online on the visit date; an unassigned worker, the assigned worker on another day and offline mode try too; emails, exports, logs and caches are scanned.

**Expected:** only the first succeeds and is audited; the others are refused; the code appears in no email, export, log, packet download or cache.
