**Scenario:** a worker drafts a change order; an Estimator publishes it; the customer approves in person with only a drawn signature, then with a one-time code to their verified contact; the approval is retried.

**Expected:** the draft changes no scope or price; the signature-only approval is refused; the code approval binds the exact version; one new snapshot and one packet version are created; change-dependent steps unblock; unaffected work continued meanwhile.
