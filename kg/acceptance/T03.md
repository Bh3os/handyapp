**Scenario:** synthetic historical accepted estimates and issued invoices that contain an old minimum adjustment exist; the migration removing minimum logic runs.

**Expected:** their stored totals, lines and hashes are byte-for-byte unchanged; only new estimates are free of minimum logic.

**Limitation (owner decision; reviewer: Owner):** This repository never had minimum logic and imports no historical records from the previous system ([[OWN-DEC-130]]), so the scenario's migration has nothing to run on. What is tested instead: published versions, approvals, job snapshots and receipts stay byte-for-byte unchanged when policies, discounts and service content change later.
