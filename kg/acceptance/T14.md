**Scenario:** uploads of an oversized JPEG, a PDF, a file whose content does not match its extension, and an image containing a malicious payload; an 11th photo.

**Expected:** each is rejected or quarantined with a clear message; none can be fetched as approved evidence; the limits (JPEG, PNG, WebP; size and count limits) are enforced on the server.
