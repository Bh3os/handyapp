**Scenario:** API calls by each role: a Worker on an unassigned job; a Worker and Office user publishing an estimate; an Estimator issuing a refund; Office running a bulk export; the Owner removing the Estimator's publish permission.

**Expected:** each call outside [[ROLE-MATRIX]] is refused on the server; after the Owner removes publish permission the Estimator's publish is refused; queue items show only role-permitted details.
