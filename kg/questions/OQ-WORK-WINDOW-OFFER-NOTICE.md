**Question:** when staff offer windows for a work visit (after approval), does the customer get an automatic notice that windows are available to choose from?

- **Who answers:** the owner.
- **Known:** [[HH-SCH-11]] says publishing window options sends a brief automatic notice, but the one automatic-message list ([[FACT-AUTOMATIC-MESSAGES]]) names only "Estimate-visit options available" (#5) and "Work appointment confirmed" (#10); [[OWN-DEC-105]] decides the work windows and the automatic confirmation, not an options notice. Only the listed messages send without staff release ([[HH-COM-06]]).
- **Until answered:** offering work-visit windows triggers no notice; the staff app says that no automatic notice is on the list for work-visit windows. The customer sees the windows in the project's Appointments tab and the Overview asks them to choose.
