Done (2026-10-25): migration 0102. Return work of a case (`quality.return_work`): classified by people into the seven classes, the warranty window read from the reviewed completion date (inside 90 days a workmanship problem is a warranty claim), coverage and price decided by the Owner with a note and no amount; linked return visits (purpose `return_work`, through the same Start Work gate, never moving the original job) or a linked return job of the same customer; return-visit punch items corrected on a started return visit and re-checked by the Owner; costs in cents apart from the job's. Resuming after an incident (`work.work_resumptions`, `POST /staff/visits/:visitId/resume`): per worker and pause, the gate again with a site check after the pause and the packet version the hold's release made; the database moves a paused job back to in progress only with it, and after a pause refuses checklist, walkthrough and Finished writes until the worker resumed. The case closes only after the decision and every item's re-check. The PROPOSED details are in [[OQ-RETURN-WORK-DETAILS]].
