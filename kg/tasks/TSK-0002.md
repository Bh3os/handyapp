Goal: Add the GitHub Actions pipeline whose required checks gate every merge, and the requirement-to-evidence report.

Scope:
- `.github/workflows/ci.yml` with jobs `secrets` (gitleaks with repo config), `test` (lint, typecheck, unit, integration against a `postgres:16` service), `e2e` (Playwright with axe, against the built server).
- A `kg` step running `node tools/kg.mjs lint`.
- `tools/trace.mjs`: scans test titles for requirement and decision IDs and writes a gap report (requirement, evidence, missing); a separate `baseline-failures.json` keeps pre-existing failures apart from new ones.

Done when:
- A deliberate failing test and a planted fake secret each turn the pipeline red (verified in the PR, then removed).
- The three required checks are named `secrets`, `test` and `e2e`.
- CI green: `secrets`, `test` (lint, typecheck, unit, integration) and `e2e`.
- Graph: this task set to `status: done`; `node tools/kg.mjs index && node tools/kg.mjs lint` reports 0 problems.
