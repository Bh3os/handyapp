Goal: Every important action can write an audit event in the same transaction, and nothing can change it afterwards.

Scope:
- `audit_events` table; UPDATE and DELETE revoked and blocked by trigger.
- `audit.record(tx, {actor, action, target, summary})` with schema-based redaction of secret fields; request ID correlation.
- Structured logger (pino) with redaction paths for tokens, codes, passwords and access instructions.

Done when:
- Integration tests: update or delete of an audit row fails; redacted fields never appear in the row or in captured logs.
- CI green: `secrets`, `test` (lint, typecheck, unit, integration) and `e2e`.
- Graph: this task set to `status: done`; `node tools/kg.mjs index && node tools/kg.mjs lint` reports 0 problems.

Out of scope:
- The audit viewer and visibility rules (Cases, dashboard, staff and privacy phase).
