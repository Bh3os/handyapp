Goal: One modular Fastify application whose routes declare their contract, so later features get validation, errors, idempotency and pagination for free.

Scope:
- `apps/server`: app factory, module registration (`src/modules/<name>`), JSON-schema request and explicit response schemas (undeclared fields stripped).
- Per-route metadata required: actor, permission, idempotency, rate limit, audit, covering test; `pnpm openapi` writes `openapi.json`, CI fails when it differs from the routes.
- Safe error shape `{code, message, fields, requestId}` and consistent status codes; expected-version (`If-Match`) helper; `idempotency_keys` table scoped by actor and operation with body hash; cursor pagination with a maximum page size; `Cache-Control: private, no-store` by default.

Done when:
- Integration tests: replayed key returns the stored response, same key with a changed body is a 409, stale version is a 409, page size is capped, unknown response fields are stripped.
- CI green: `secrets`, `test` (lint, typecheck, unit, integration) and `e2e`.
- Graph: this task set to `status: done`; `node tools/kg.mjs index && node tools/kg.mjs lint` reports 0 problems.
