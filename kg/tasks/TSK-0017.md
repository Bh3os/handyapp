Goal: One server answering two hosts with separate surfaces and cookies, per [[OWN-DEC-133]].

Scope:
- Host routing from `PUBLIC_ORIGIN` and `STAFF_ORIGIN`: the public host serves the Astro site, `/portal/*`, `/api/public/*`, `/api/customer/*` and `/webhooks/*`; the staff host serves the staff SPA and `/api/staff/*`; every API answers 404 on the wrong host.
- Host-only cookies per origin; staff sign-in never inherited by the portal and the reverse.
- No CORS: same-origin calls only; `docs/architecture.md` records that the cross-origin API rules do not apply.
- Security headers: HSTS, CSP, `Referrer-Policy: no-referrer` on private routes, frame denial; staff host and portal routes `noindex`.

Done when:
- Integration tests: staff API on the public host is 404, a staff cookie is not sent to the public host, preflight requests get no CORS allowance.
- CI green: `secrets`, `test` (lint, typecheck, unit, integration) and `e2e`.
- Graph: this task set to `status: done`; `node tools/kg.mjs index && node tools/kg.mjs lint` reports 0 problems.
