Goal: All money arithmetic in one tested package that never uses floating point.

Scope:
- `packages/money`: branded `Cents` integer type with currency `USD`, sum, line total (quantity in minor units of the unit), percentage of an amount with explicit half-up rounding to cents, allocation without remainder loss, `en-US` formatting.
- Lint rule or type guard rejecting `number` money values at module boundaries.

Done when:
- Unit and property-based tests: sums are exact, a 20% share of any amount rounds once to cents, no API accepts a float.
- CI green: `secrets`, `test` (lint, typecheck, unit, integration) and `e2e`.
