Goal: Staff sessions that expire, rotate and can be revoked, with optional TOTP MFA and a fresh-sign-in check for owner-only actions.

Scope:
- Idle timeout from configuration, session rotation on sign-in, revoke-all, `__Host-` cookies with `Secure`, `HttpOnly`, `SameSite=Strict`.
- CSRF token on unsafe methods; `requireFreshAuth(minutes)` guard for later owner-only actions.
- Optional TOTP enrollment with recovery codes, recommended for the Owner.

Done when:
- Integration tests: idle session expires, revoke-all ends every session, a missing CSRF token is rejected, MFA challenge required once enrolled.
- CI green: `secrets`, `test` (lint, typecheck, unit, integration) and `e2e`.
