Goal: Decided owner values are active configuration with their source IDs; unknown values are an explicit NOT CONFIGURED state, never a default.

Scope:
- `policy_versions` table: key, version, value (money in cents), source fact or decision ID, effective from.
- Seed from the FACT nodes listed in `uses`; open facts seed as NOT CONFIGURED.
- Typed accessor `config.get(key)` returning `{value, version}` or `NOT_CONFIGURED`; callers must handle both (type-enforced).
- AI module flag present and off; the "AI disabled" state has its own test.

Done when:
- Tests: every seeded value carries its source ID; reading an open fact yields NOT_CONFIGURED; the AI-disabled test passes.
- CI green: `secrets`, `test` (lint, typecheck, unit, integration) and `e2e`.
- Graph: this task set to `status: done`; `node tools/kg.mjs index && node tools/kg.mjs lint` reports 0 problems.
