Scope:
- `acknowledgments` per worker and packet version; critical-change classification; removed assignments lose access.

- Integration tests: critical change clears acknowledgment once; a new worker must review personally.
- The `tested_by` scenarios pass for this slice; tests are tagged with the `implements` IDs.

Built 2026-10-21 before the 2026-10-21 decisions (merged with them 2026-10-22).
